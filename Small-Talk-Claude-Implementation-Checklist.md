## Where the theme stands today (verified 9 Oct, preview + source read)

- Theme is a Horizon base with Dawn assets layered on top and a custom `desi` layer (desi.css / desi.js / desi-motion.js / di-* sections) that bypasses both frameworks. ~800 files, most unused. settings_data still carries old Dawn colour schemes and `assistant` fonts; the real brand styling is hardcoded in desi.css.
- Hero motion: a working but fragile `desi-hero` custom element. Finite 3-set autoplay, hold-to-pause, tone switch, swipe, visibility/offscreen pause, reduced motion all exist in code.
- Hero artwork: three PNG atlases (characters 2.9 MB, fingers 1.5 MB, hand base 1.4 MB, nails 1.1 MB, hands 1.0 MB, accents 1.1 MB) = ~9 MB on first paint. No WebP/AVIF, no per-product split.
- Preview hand is the brief-rejected five-nail version; it overlaps the headline on mobile. Character crops show hard rectangular edges.
- Landing order matches the approved sequence. Chapters are thin: nails row + caption + art; no story beat, the dashed thread crosses content.
- Products are DRAFT so the theme rewrites every product link to `/?view=desi-preview-product-*` preview templates. Real PDP/cart/collection templates are effectively untested.
- Red (`#a00027`) is used for every heading, product name, PDP title, cart title, page title and teaser, directly beside the blue logo.

## Motion code review (desi.js / desi-motion.js / desi.css)

| # | Finding | Severity | Fix |
|---|---|---|---|
| M1 | Flight layer is `position:fixed` on `body`, geometry captured once from `getBoundingClientRect`. Scrolling mid-flight detaches the nail. | High | Render flight inside the hero (absolute, hero-relative coords) or recapture on scroll; cancel flight on scroll > N px. |
| M2 | Donor preview nail is rotated −143° via CSS; flight uses the rotated element's bounding box as source, then starts its own rotation at −28°. Visible jump at take-off. | High | Compute source anchor from un-rotated geometry + known rotation; interpolate rotation from the real source angle. |
| M3 | Accent-flight: after landing, `clearFlight` restores the side accent sample while the main nail also shows the accent — duplicate nail during the accent hold. | Medium | Keep the accent sample hidden through the hold; restore only on return-flight end. |
| M4 | Five-nail preview hand; `ROWS` map hardcoded per product in JS and duplicated in `di-nail-sequence` Liquid. | High | Four-visible-nail hand (new asset), single source of truth for mapping (metaobject or one JSON). |
| M5 | ~9 MB of PNG atlases as CSS backgrounds; nothing lazy, nothing responsive, no preload for the actual LCP image. | High | Per-product WebP/AVIF sprites, preload first product only, lazy decode the rest, reserve dimensions. |
| M6 | desi.css is patch-on-patch: `.di-main-nail` bottom redefined four times, `.di-finger` three times, cuticle registration comments contradict each other. | Medium | Rewrite hero CSS once with named custom properties for anchor geometry. |
| M7 | Skin-tone atlas positions are fudge values (`3.27%`, `35.09%`…) implying the four tiles are not evenly spaced in the atlas. | Low | Re-export finger atlas on an exact 4×1 grid. |
| M8 | Review-mode link rewriting (`DesiReviewRoutes`) mutates every `<a>` on the page; it will silently break the real routes once products go live. | Medium | Remove once products are active; never ship it. |
| M9 | Reduced motion handled; keyboard hold handled; hidden/offscreen handled; cleanup in `disconnectedCallback` handled. | OK | Keep the clock (`DesiMotion`) — it is clean and testable. |
| M10 | Character crop uses `clip-path: ellipse` on an atlas with hard edges; rectangles show on several sets. | Medium | New character art with transparent, feathered silhouettes; no clip-path. |
