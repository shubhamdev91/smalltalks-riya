What is the difference between a Shopify connector and a Shopify plugin?

### Assistant · 2026-10-09 05:31:12

In Claude, a **connector** lets Claude reach your Shopify store's data. A **plugin** is a packaged set of instructions and workflows that tells Claude how to carry out a task, and it can include connectors.

## Shopify connector
- **What it is:** a link to Shopify's MCP server, authorized with your Shopify account.
- **What it gives Claude:** tools that act on your store, like searching and creating products, listing orders and customers, setting inventory, creating discounts, running ShopifyQL analytics, and making GraphQL queries.
- **What it doesn't include:** any process. Claude has the tools but decides how to use them each time.
- **Where you manage it:** your claude.ai connector settings.
- **Your account:** you already have a Shopify connector working in this session.

## Shopify plugin
- **What it is:** an installable bundle of skills, slash commands, subagents, hooks, and sometimes connector settings.
- **What it gives Claude:** a repeatable method. Examples: "run the weekly sales report this way," "launch products using this checklist," or "check inventory and flag anything low."
- **How it relates to the connector:** a plugin usually *uses* a connector. It can include the connector's settings, so installing the plugin also sets up the link.
- **Where you manage it:** your organization's plugin catalog in Claude.

## Side by side

| | Connector | Plugin |
|---|---|---|
| Gives Claude | Access to your store and the actions it can take there | Know-how and workflows |
| Contains | Tools (API calls) | Skills, commands, agents, hooks, possibly connectors |
| Without the other | Works, but Claude improvises each time | Can't touch store data unless a connector is set up |

**Rule of thumb:** use the connector alone for occasional one-off tasks. Add a plugin when you repeat a Shopify process and want it done the same way every time.

If you meant "plugin" in Shopify's own sense, Shopify calls those add-ons **apps**. They install into your store from the Shopify App Store and run inside Shopify, and they have nothing to do with Claude.
