# Incoming ChatGPT images — how to identify them

The owner will NOT rename files. They arrive with ChatGPT's default download names (e.g. "ChatGPT Image Oct 10, 2026, 11_02_15 AM.png")
in three folders. Identify each file by its download order (file time) AND by looking at it. If a folder has more files than listed
(retries), match visually and keep the latest good one. If one is missing, report it; don't guess.
